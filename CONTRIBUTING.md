# Contributing

Tempo shares its code as is. It does not take issues or pull requests.

Tempo is built on [T3 Code](https://github.com/pingdotgg/t3code). Report T3 Code bugs, and read
T3 Code's contribution guide, in its own repository.

To build and change Tempo for yourself, start with the
[development runbook](docs/operations/development.md#first-checkout) and [AGENTS.md](AGENTS.md).
